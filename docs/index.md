# Guia de uso MkDocs

## O que é o MkDocs?
&emsp; O MkDocs é um gerador de sites estáticos rápido, simples e voltado para a criação de documentação técnica de projetos. Os arquivos de documentação são escritos em Markdown (.md) e a estrutura do site é configurada em um único arquivo YAML (mkdocs.yml).

&emsp; O MkDocs acompanha um servidor local integrado que atualiza automaticamente o navegador sempre que um arquivo for alterado e salvo.
